# Google Gemini

## Descrição

Este diretório contém os **resultados produzidos pelo VeritasSec** durante os experimentos realizados utilizando o provedor **Google Gemini**.

Os arquivos disponibilizados permitem reproduzir, inspecionar e validar as saídas apresentadas no artigo submetido ao SBSeg 2026.

---

## Conteúdo

Os resultados incluem, conforme aplicável:

- Relatórios de análise em **CSV**;
- Relatórios estruturados em **JSON**;
- Relatórios em **Markdown**;
- Arquivos **SARIF enriquecidos** produzidos pelo VeritasSec;
- Métricas de execução;
- Gráficos estatísticos gerados automaticamente;
- Arquivos auxiliares utilizados na consolidação dos resultados.

---

## Organização

Cada diretório corresponde a uma execução independente do VeritasSec.

Exemplo:

```
Juice_Shop_20260513_212317-analitico/
```

Dentro de cada execução encontram-se todos os artefatos produzidos automaticamente pela ferramenta.

---

## Objetivo

Os arquivos disponibilizados permitem:

- reproduzir os resultados apresentados no artigo;
- inspecionar as classificações produzidas pelo VeritasSec;
- analisar o enriquecimento contextual realizado sobre os resultados SAST;
- consultar métricas e gráficos gerados durante o processamento.

---

## Observações

Todos os arquivos foram gerados automaticamente pelo VeritasSec e correspondem aos resultados obtidos utilizando modelos da família Google Gemini.
